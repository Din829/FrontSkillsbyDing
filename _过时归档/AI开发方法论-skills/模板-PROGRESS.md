## Step 1：标题（YYYY-MM-DD）

### 做了什么

具体改动，文件级。简洁。

### 信念检查

哪几条信念相关？符合 / 边界 / 违反？违反必须显式说为什么 + 用户是否同意。

### 承诺审计

兑现哪条承诺？测试是 [shape] 还是 [behavior]？

> shape = 返回值字段对；behavior = runtime 真生效。
> 只测 shape 容易出"测试过 + 实际没生效"——这是实战教训。
> 另两问：mock 有没有掩盖真实行为？单次孤证（有抖动的）算不算数？

### 事实核查

用到的 SDK / API / 库 + 核查方式：[亲查源码 / 读官方文档 / 凭印象（必须升级）]。

### 范围检查

改动是否在计划内？diff 回看了吗？顺手改的有没有 / 保留还是 revert？
