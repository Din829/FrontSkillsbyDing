# 采样设计（在正文选择前记录）

目的：找出值得实验的选题与表达方式，服务点赞和注目度 KPI；本轮不声称证明标题或内容的因果效果。

元数据范围由 sampling-plan.json 预先声明：ai、llm、claudecode、agent、rag、mcp 各采 latest 600 篇及 alltime 100 篇，另取全站 alltime 200 篇。标签重叠去重。实际返回不足则记录 API 终止原因，不补成虚构样本。这里的 alltime 是网站提供的排序名，不等于严格按 liked_count 排序，更不等于已证明的全站点赞最高文章。

资源计划：元数据约 44 次列表请求；正文目标 160 篇；加探测、验证后网络请求控制在约 300 次，每次至少间隔 1.1 秒。超出计划如需增加样本，先留下原因与新预算。不限模型费用不代表无限给公共站点施加请求。

正文选样：对 latest 各主题按发表月份分层；排除发表未满 7 天的文章用于热门/普通比较。每个主题取日期跨度相对接近的较高点赞与较低点赞配对，匹配窗口优先 14 天；保留实际日期差，不能匹配的单独标记。全局补充历史高互动案例用于定性参考，和 recent 对照分开。同一文章不重复拉取，固定随机种子 20260925。选择清单在拉取正文前生成。

分析：在相同主题和月份内比较标题形式、字数段与点赞的关联；另按作者限制权重做敏感性检查。正文特征用结构解析（段落、代码、图表）与明确注明为启发式的文本标签；人工抽读核对结构和真实内容，不能把命中“検証”当成真的做过实验。报告样本数、零赞比例及中位数，不只报容易受爆款影响的均值。不用点赞除以天数冒充公平归一化；没有曝光、点击、完读数据，无法测真实点击率或点赞转化率。

原始响应仅作本地研究证据，不发布或再分发全文，不采评论者信息作画像。公开报告只链接原文并简述观察。禁止使用 /search、付费或登录绕过。robots.txt 不是访问授权证明；已读取 terms，遵循低负荷访问和不转载约束，遇到拒绝或限流停止并记录。
