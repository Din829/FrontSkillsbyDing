# 实验执行

## 做什么

读取 `experiment-plan.md` 和相关校准材料，真实运行命令。把输入标识、环境、参数、输出、退出状态与失败保存在 `results/`；汇总写入 `execution.md`，附一条可重跑命令。更新运行记录和候选断言，机器格式只查[证据契约](../evidence-check/references/contract.md)。

保留原始记录，派生指标写清分母、单位、筛选和计算方式。补跑另留记录并说明原因，不只重跑表现差的一方。亲看实际产物或关键副作用，不能用退出成功代替业务正确。调用量、耗时和可得的费用如实记录，估算与真实账单分开。

## 什么时候做

方案已有可运行步骤时。环境失败、负面结果和证据不足都交给下游判断，记录实际发生了什么。校准疑问随结果一起保留，不靠编造数据消除疑问。

将问题、方案、原始结果交给独立审查；作者解释另放 `execution.md`，便于先看证据后看结论。共享授权、继续与结束规则见 [policy.json](../../policy.json)。

## 具体例子

模型调用一部分成功、一部分超时：保存每次响应与错误，区分“已完成样本中的正确率”和“包含超时的任务完成率”。缺失样本不能填预计答案；实验未完成也不能据此断言方法无效。复现者拿到相同输入和命令，应能看见失败如何进入统计。
