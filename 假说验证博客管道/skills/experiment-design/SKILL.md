# 实验设计

## 做什么

读 `hypothesis.md`，用[方案模板](../../templates/experiment-plan.md)写 `experiment-plan.md`，交代输入、对照、指标和复现命令。用一句话说明：指标变好，为什么代表原问题改善？保持输入、资源和调参机会可比，无法一致的地方说明影响。

校准是在真实任务上比较独立已知的好方案与坏方案，看尺子能否拉开差距。只验证 hit@k 等公式算对了，不算任务校准。保存实际输入输出到 `results/`，解释写入 `ruler_check.md`，机器记录按[证据契约](../evidence-check/references/contract.md)填写。

先小跑基线，检查是否已接近满分，或与已知坏方案差不多。由审查者判断是否应换题、换尺子或缩小结论；校准和天花板预检不是新增 gate 条件。

## 什么时候做

正式实验前，或输入、指标发生实质变化时。随机任务先看波动再决定样本与重复；LLM 裁判可用独立参考、交换顺序和长短对照检查偏好。无需固定次数。共享流程见 [policy.json](../../policy.json)。

## 具体例子

检索实验用同一批实际文档和有依据的问答，把相关文档排前作为已知好方案，随机排序作为坏方案，比较评分分布；再试基线。若基线几乎全对，新增更贴近工作难点的问题后再评估，不把无差异包装成两个方案等效。
