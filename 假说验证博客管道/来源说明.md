# 来源说明

- `scripts/pipeline.py`：gate 提前到独立审查之前跑，并把"未登记为实测的数字"清单交给审查者核对（原顺序下，文末追加一句编造的百分比只会得到 warning，审查者也看不到）。对应测试 `tests/test_pipeline_round2.py::test_unregistered_numbers_reach_reviewer`。

## 没有复制的内容（仓库公开）

| 排除项 | 原因 |
|---|---|
| `archive/` | 第一、二轮的历史快照（约 95MB），仅用于追溯 |
| `research/zenn/raw`、`results/raw`、`reading` | 第三方 Zenn 文章的正文快照，不能公开再分发 |
| 各 run 的 `sessions/` | 模型会话原始日志，含本机路径与完整提示 |
| `corpus.json` | 检索实验用的本人博客原文（含未发布稿） |
| `tests/round2-gate-*` | 测试运行时产物，可由测试脚本重新生成 |

因此本目录内依赖上述原始数据的复现命令（Zenn gate 严格检查、检索实验复跑）无法直接执行，需回原目录运行。
