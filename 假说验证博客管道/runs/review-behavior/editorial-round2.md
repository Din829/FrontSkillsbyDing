# 审查稿第二轮编辑说明

课题：旧稿的方法和限制较分散，容易把“skills 没有取得额外优势”与“评分器误伤了合理回答”混在一起。

为什么这样改：先回答最有用的发现——不合格答案也可能是评分器的问题，同时保留原比较未支持 skills 增益的结论。图把原始自动分数、核心判断与事后语义复核分开，明确事后复核没有覆盖或改写原分数。

推荐标题：`AIレビューの不正解を読んだら、採点ルールが狭すぎた`。它对应真实排查经历与读者动作，不暗示模型能力提升。备选 `レビュー用の指示を増やす前に、不合格の理由を読む` 强调实践建议，但不如推荐标题明确本次发现。这里的吸引力判断是编辑推断。

Zenn 研究用于决定“具体问题、真实产物、可复用动作”的表达，而不是套爆款数字。代码直接读保存的答案和许可标签，输出真正导致失分的额外标签。图片显示来自旧记录的比较，不声称插图导致点赞增加。

| 改动 | 预期帮助 |
|---|---|
| 开头直接说误伤与原比较结果 | 不必读完整段实验介绍才知道发现 |
| 自动分数、核心判断、事后复核并列画图 | 看清三者并非同一个指标，也不是修正后模型变强 |
| 用不公平基线的真实答复展开 | 理解额外标签为何合理，而不是仅看抽象评分规则 |
| 提供可运行的标签差集代码 | 读者能检查自己评分器落掉了什么 |
| 集中说明人工情境、非盲事后判断与模型配置 | 减少逐段打预防针，仍保留关键证据边界 |

来源与生成：使用现有 `results/metrics.json`、`results/original-accounting.json`、语义复核、原始答复和参考标签。生成/验证脚本与结果在 `reports/round-2/editorial/`。短代码从稿件原样提取执行，输出与稿件一致；图像已实际查看。追加模型确认写作自然日语，不使用中文“补测”或“通用提示”。

独立性与限制：图右侧是另一个 AI 知道争点后的语义判断，不是盲测真值。本轮没有新题、没有调用模型、没有把旧主指标改为成功。既有题集的核心判断已经没有可观察改善余地，是对这批记录的判断，不能外推真实工作等效。

返工记录：本次为用户要求的第二轮内容重写；图和代码的计划内初次生成不是返工。真实校验首次通过，随后自审一轮，将首段“失分回答均合理”的断言标签明确为读取既有语义复核的 read，与检索稿措辞修正同轮处理。没有自动 gate 返工；最终数字检查交主编排者。旧文档和原始记录保持不动。
