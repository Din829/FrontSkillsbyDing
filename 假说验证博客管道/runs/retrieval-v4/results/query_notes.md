# 独立检索题编制记录

此题集由独立代理阅读 Blog 现有技术文章后编写；编题时未读取检索算法、参数或结果。目的为检验本地文章查找，不验证原博客技术主张是否真实或最新。

- 共 28 题：14 个主题级问题、14 个正文细节问题；中文 9、日文 11、英文 8。
- 主文章覆盖 14 个不同主题，题目是人工选择的便利样本，不代表真实访问或搜索分布。
- `kind` 由 topic/detail 和 zh/ja/en 组成；中英文问题寻找日语文档属于跨语言检索，但不保证每题都需要翻译模型。
- `relevant_paths` 相对 Blog 根目录，使用正斜线。任何一篇符合均算文档命中；不是要求全部返回。
- `evidence_quote` 是至少一个已列相关文档中的逐字片段，用来核对题目确实可回答，不用于给检索器提示答案。多相关文档时引文不保证逐字存在于每篇。
- 对存在完整同主题技术稿的 Gemini CLI 和 Agentic RAG 题补充了多个可接受来源；相关集仍可能不完整。评分前可独立核对其他候选是否也能回答，但须披露补标，不可只给某方法有利的结果补标。
- 排除个人指定忽略目录、代码项目 README/AGENTS、写作规范、空大纲和社交短帖。`prompt注入，LLM安全/article.md` 主要是注释大纲，完整文章是 `blog_article.md`。
- 题目应在算法结果出来前冻结。语料 manifest 必须包含所有被列为相关的文档；否则是数据配置错误，不计检索失败。

编制后用独立只读 Python 检查：28 个唯一 ID、所有引用路径存在、每条引文在至少一个相关文件中逐字存在，未发现错误。此检查只验证可定位性，不等于人工相关性已经穷尽。
