# transitions-dev（12 个纯 CSS 过渡，MIT）

> 来源：<https://github.com/Jakubantalik/transitions-dev>（Jakub Antalik，也是 thinking-orbs 的作者；MIT，41KB）。同步于 2026-08-19，上游克隆在 `参考项目/前端与设计/transitions-dev/`。
> 入口：[`skills/transitions-dev/SKILL.md`](skills/transitions-dev/SKILL.md)——它本身就是 SKILL 格式，直接照它的表选。

**管什么**：功能型界面里最常见的 12 种"状态切换"过渡——卡片尺寸变化、数字弹入、通知角标、文字原位换、下拉菜单、弹窗开关、面板滑入、列表↔详情左右滑、图标互换、成功对勾、头像组 hover、错误抖动。全是 `t-*` 命名空间的纯 CSS + 语义化 CSS 变量，**零框架依赖，每个自带 `prefers-reduced-motion`**。

**跟 gsap / react-bits 怎么分**：
- 要的是**UI 状态切换的体面过渡**（开 / 关 / 换 / 抖）→ 先来这里，贴 CSS 就完
- 要**滚动驱动 / 时间线编排 / 复杂 choreography** → `../../frontend-motion-gsap.md`
- 要**炫的现成动效组件**（文字 / 背景 / 特效）→ `../react-bits/`
