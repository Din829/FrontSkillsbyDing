# React Bits 组件中文索引

> 共 **134 个**动效组件,分 4 类。原仓库:[DavidHDev/react-bits](https://github.com/DavidHDev/react-bits) · 官网:[reactbits.dev](https://reactbits.dev/)

## 怎么用这份清单

- **找组件**:按下面分类 + 一句话效果定位你要的动效。
- **拿源码**:每个组件有 4 种技术栈变体,按你项目选一套目录拿对应文件:
  | 技术栈 | 目录 | 后缀 |
  |---|---|---|
  | JS + 原生CSS | `src/content/<分类>/<组件>/` | `.jsx` |
  | JS + Tailwind | `src/tailwind/<分类>/<组件>/` | `.jsx` |
  | TS + 原生CSS | `src/ts-default/<分类>/<组件>/` | `.tsx` |
  | TS + Tailwind | `src/ts-tailwind/<分类>/<组件>/` | `.tsx` |
  例:要 TS+Tailwind 版的 BlurText → `src/ts-tailwind/TextAnimations/BlurText.tsx`
- **看依赖**:组件只依赖自己 import 的库(看文件头)。带 `@react-three/*` 的是 Three.js/WebGL 重组件;带 `motion` 的是 Framer Motion;带 `gsap` 的是 GSAP。

## 备注

- **本清单已逐个比对 134 个组件源码核对过**(读 props + 核心动画逻辑 + import 依赖),订正了 2 处描述错误(ReflectiveCard 实为摄像头背景、InfiniteMenu 实为球面吸附菜单)和十余处偏差。剩余描述方向准确,细枝末节(各组件还有大量可配 props 变体)未尽列。
- 唯一仍存的不确定:纯视觉的细微观感(如"柔光"vs"波纹")以官网 demo 或本地实跑最终确认;但"是什么效果、怎么触发"已与源码对齐。
- 想看真实动效:官网每个组件页有实时预览;或在本仓库根目录 `npm install && npm run dev` 跑起 demo 站。
- 技术线索仅标主要依赖,实际以组件文件头 import 为准。
